# New Luxora Things

A simple marketing website project built with HTML, CSS, and JavaScript.

## Project Structure

- `index.html` - Main website page and entry point.
- `styles.css` - Global styles and layout rules.
- `scripts/script.js` - JavaScript behavior and interactivity.
- `static/` - Static assets used by the site.
  - `icones/` - Icon images and graphic assets.

## Notes

- Use `index.html` to preview the site in a browser.
- Update `styles.css` to change the visual design.
- Add or modify site behavior in `scripts/script.js`.
- Place image and icon assets inside `static/icones/`.

## Getting Started

1. Open `index.html` in your browser.
2. Edit the files as needed.
3. Commit changes to GitHub for version tracking.
